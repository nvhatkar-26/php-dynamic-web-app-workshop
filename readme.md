# PHP Dynamic Web Applications Workshop

## 📌 Overview

This workshop teaches how to build dynamic web applications using PHP and MySQL.

## 🎯 What You Will Learn

* PHP basics
* Handling forms (GET & POST)
* Connecting PHP with MySQL
* Performing CRUD operations
* Building a mini project (Student Management System)

## 🛠️ Requirements

* XAMPP installed
   * Downaload XAMMP at https://www.apachefriends.org/download.html
* Code Editor (VS Code recommended)
   * Download VS Code at: https://code.visualstudio.com/docs?dv=win    

## ⚙️ Setup Instructions

1. Start Apache and MySQL in XAMPP
2. Import `setup/database.sql` into phpMyAdmin
3. Place project folder in:

   * `htdocs` (XAMPP)
4. Open browser:
   http://localhost/php-dynamic-web-app-workshop/

## 📂 Project Structure

* starter-code → students work here
* final-project → completed solution
* setup → database setup

## 🚀 Mini Project

Build a Student Management System with:

* Add Student
* View Students
* Edit Student
* Delete Student
